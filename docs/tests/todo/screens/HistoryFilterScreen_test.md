# 測試規劃：HistoryFilterScreen_test.md

## 1. 測試目標
本彈窗提供歷史紀錄的各種過濾條件。驗證 HistoryFilterScreen 能正確顯示所有靜態篩選條件（日期、球數等）與動態的自訂彙整欄位，且套用和清除動作能正確回傳。

## 2. 測試案例 (Test Cases)

### 2.1 【前端元素】
- **渲染篩選器畫面**
  - **預期結果**: 顯示「標題或結果包含」、「開始/結束日期」、「最少/多球數」、「備註包含」等欄位，以及「清除」、「套用」按鈕。

### 2.2 【互動邏輯】
- **渲染並編輯自訂欄位篩選**
  - **預期結果**: 若系統有設定自訂打席彙整欄位，畫面上應出現對應的 TextInput 來過濾該欄位的值。
- **輸入日期區間及球數**
  - **輸入**: 改變日期與球數 Input 的值。
  - **預期結果**: 本地狀態 localFilters 被正確更新。

### 2.3 【功能邏輯】
- **點擊套用篩選**
  - **預期結果**: 點擊「套用」後呼叫 `onApply` 傳回完整 filter payload，並觸發 `navigation.goBack()`。
- **點擊清除篩選**
  - **預期結果**: 點擊「清除」後呼叫 `onClear` 並返回。
