# 測試規劃：HistoryDetailScreen_test.md

## 1. 測試目標
驗證 HistoryDetailScreen 呈現單一打席所有投球的詳細記錄、繪製 PitchGrid 以及逐球修改與刪除打席的動作。

## 2. 測試案例 (Test Cases)

### 2.1 【前端元素】
- **無資料時渲染**
  - **預期結果**: 顯示「無資料」畫面。
- **有資料時渲染九宮格與自訂欄位**
  - **預期結果**: 顯示標題、PitchGrid 區域，且下方的清單有正確顯示每球的結果、速度、自訂欄位。

### 2.2 【互動邏輯】
- **點擊編輯單顆球**
  - **輸入**: 點擊單球列表的卡片或編輯 icon。
  - **預期結果**: 導向 PitchEdit 頁面並傳遞正確參數。
- **單顆球的刪除觸發**
  - **預期結果**: 自 PitchEdit 觸發 onDelete callback 後，會跳出警告視窗詢問是否刪除，確認後更新 DB。

### 2.3 【功能邏輯】
- **刪除整筆打席紀錄**
  - **輸入**: 點擊畫面最底下的「刪除此打席紀錄」。
  - **預期結果**: 彈出確認警告。點擊確認後呼叫 API `deleteAtBatSummary`，並退回上一頁。
