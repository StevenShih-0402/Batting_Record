# 測試規劃：PitchEditScreen_test.md

## 1. 測試目標
這是一個給既有單球紀錄使用的編輯畫面。驗證 PitchEditScreen 渲染既有的資料、允許修改一般欄位與自訂欄位，以及執行儲存更新或刪除的邏輯。

## 2. 測試案例 (Test Cases)

### 2.1 【前端元素】
- **渲染單球編輯畫面含資料**
  - **預期結果**: 能夠看到傳入紀錄的結果、位置資訊，並在表單內帶入原本的球種、球速及自訂欄位值。

### 2.2 【互動邏輯】
- **修改自訂欄位值**
  - **輸入**: 變更 TextInput 中的文字或重新選擇 Dropdown。
  - **預期結果**: 觸發 `setCustomValue`，並在儲存時連同其他欄位一併更新。

### 2.3 【功能邏輯】
- **點擊更新變更**
  - **輸入**: 點擊頂部的「更新」按鈕。
  - **預期結果**: 呼叫 `handleSave`，並透過 callback 更新上一層狀態。
- **點擊刪除此球**
  - **輸入**: 點擊「刪除」按鈕。
  - **預期結果**: 呼叫 `onDelete` callback 並退回上一頁。
