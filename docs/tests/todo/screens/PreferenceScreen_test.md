# 測試規劃：PreferenceScreen_test.md

## 1. 測試目標
驗證 PreferenceScreen 的偏好設定功能，包含主題色選擇、自訂球種新增與刪除、自訂打席備註欄位(包含文字與下拉選單)的新增與刪除，以及自訂打席彙整欄位的新增與刪除，最後驗證儲存行為。

## 2. 測試案例 (Test Cases)

### 2.1 【前端元素】
- **渲染偏好設定畫面基本元件**
  - **預期結果**: 顯示「主題顏色」、「自訂球種」、「自訂打席備註欄位」以及「自訂打席彙整欄位」等區段，並顯示主要的「儲存變更」按鈕。

### 2.2 【互動邏輯】
- **選擇主題顏色**
  - **輸入**: 點擊某個顏色區塊。
  - **預期結果**: 觸發 localColor 的更新。
- **新增自訂球種**
  - **輸入**: 輸入「新球種」並點擊新增按鈕。
  - **預期結果**: 「新球種」出現在下方的 Chip 列表中，且輸入框清空。
- **刪除自訂球種**
  - **輸入**: 點擊某個球種 Chip 的關閉按鈕。
  - **預期結果**: 該球種從列表中移除。

### 2.3 【自訂欄位邏輯】
- **新增文字型自訂欄位**
  - **輸入**: 在備註欄位區塊，輸入欄位名稱並選擇「文字輸入」，點擊「新增此欄位」。
  - **預期結果**: 該欄位新增至 Chip 列表中。
- **新增下拉選單型自訂欄位與選項**
  - **輸入**: 選擇「下拉選單」，新增至少一個選項，點擊「新增此欄位」。
  - **預期結果**: 選項順利新增並能將欄位加入列表中。
- **刪除自訂欄位**
  - **輸入**: 點擊某個自訂欄位 Chip 的關閉按鈕。
  - **預期結果**: 該爛位從列表中移除。

### 2.4 【功能邏輯】
- **儲存變更**
  - **輸入**: 點擊「儲存變更」。
  - **預期結果**: 呼叫 `savePreferences`，成功後顯示 Toast 提示並觸發 `navigation.goBack()`。
