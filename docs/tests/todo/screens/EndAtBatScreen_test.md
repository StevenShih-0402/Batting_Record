# 測試規劃：EndAtBatScreen_test.md

## 1. 測試目標
驗證結束打席時填寫彙整資料的畫面，確保能正常寫入一般備註及自訂彙整欄位，並透過 Queue 實現快選功能。

## 2. 測試案例 (Test Cases)

### 2.1 【前端元素】
- **渲染儲存打席紀錄 Modal**
  - **預期結果**: 顯示目前好壞球數、標題輸入框、總結備註，以及自訂彙整欄位。最後有一個「儲存並清空」按鈕。

### 2.2 【互動邏輯】
- **帶入 Queue 選項並點擊快選**
  - **預期結果**: 與 PitchInput 類似，針對 text 型的彙整欄位應拉出 Queue chip，點擊後會自動填入該欄位。

### 2.3 【功能邏輯】
- **點擊儲存並清空**
  - **輸入**: 填妥資料點擊儲存。
  - **預期結果**: 執行 `handleSaveWithQueue` 並呼叫 `onSave` callback，最終呼叫 `navigation.goBack()` 返回。
