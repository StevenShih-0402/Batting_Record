# 測試規劃：BattingListScreen_test.md

## 1. 測試目標
此畫面隸屬於記錄打席中的「條列模式」。它從 `useAtBatRecords` 取得資料，需要測試空狀態與有資料狀態的列表渲染，以及點擊「儲存紀錄 (彙整)」或單球紀錄時的導航功能。

## 2. 測試案例 (Test Cases)

### 2.1 【前端元素】
- **渲染空狀態**
  - **預期結果**: 顯示「尚無打席紀錄。」，且「儲存紀錄 (彙整)」按鈕不可點擊。
- **渲染逐球紀錄列表**
  - **預期結果**: 清單中顯示每球的結果、球種、球速以及自訂欄位的資訊，同時左側有一個帶顏色的圓圈與序號。

### 2.2 【互動邏輯】
- **點擊單一項目進行編輯**
  - **輸入**: 點擊清單中的某一球。
  - **預期結果**: 觸發 `navigation.navigate('PitchEdit')` 並附帶對應 record。

### 2.3 【功能邏輯】
- **點擊儲存紀錄**
  - **輸入**: 點擊「儲存紀錄 (彙整)」按鈕。
  - **預期結果**: 觸發 `navigation.navigate('EndAtBat')` 並附帶目前的 records 陣列資料。
